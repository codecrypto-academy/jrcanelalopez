# web2.5.diseño

Este proyecto es una base para el diseño y desarrollo de aplicaciones web que exploran conceptos de Web 2.5, integrando elementos de Web2 y Web3 para ofrecer experiencias modernas y seguras.

## Introducción

web2.5.diseño busca facilitar la creación de interfaces y flujos de usuario que aprovechan tecnologías descentralizadas sin perder la usabilidad y accesibilidad de la web tradicional.

## Cómo arrancar el proyecto

1. Clona el repositorio:

   ```bash
   git clone <URL-del-repositorio>
   cd web2.5-diseño
   ```

2. Instala las dependencias:

   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

4. Abre tu navegador en `http://localhost:3000` para ver la aplicación.
