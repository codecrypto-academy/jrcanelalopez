# Web2.5 Explorer

## Resumen de la Aplicación

**Frontend**: Una aplicación web interactiva que permite a los usuarios explorar datos relacionados con Web2.5. Está construida con tecnologías modernas como React.

**Backend**: Una API que proporciona los datos necesarios para la aplicación frontend. Está desarrollada con Node.js y Express.

## Cómo arrancar la aplicación

### Frontend

1. Navega al directorio del frontend:
   ```bash
   cd /ruta/del/frontend
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm start
   ```
4. Accede a la aplicación en tu navegador en `http://localhost:3000`.

### Backend

1. Navega al directorio del backend:
   ```bash
   cd /ruta/del/backend
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Configura las variables de entorno en un archivo `.env`.
4. Inicia el servidor:
   ```bash
   npm start
   ```
5. La API estará disponible en `http://localhost:5000`.

Asegúrate de que el backend esté corriendo antes de usar el frontend.
