---
description: Ejecutar tests del smart contract con Foundry
---

Ejecuta los tests del smart contract en el directorio `sc/`.

Instrucciones:
1. Cambia al directorio `sc/`
2. Ejecuta `forge test -vvv` para ver los resultados detallados
3. Si hay tests fallando, analiza los errores y sugiere correcciones
4. Muestra un resumen de tests pasados/fallados
