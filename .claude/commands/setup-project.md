---
description: Guía de configuración inicial del proyecto
---

Proporciona una guía paso a paso para configurar el proyecto desde cero.

Instrucciones:
1. Verifica pre-requisitos instalados:
   - Node.js (18+)
   - Foundry (forge, anvil)
   - Git
   - MetaMask
2. Si faltan pre-requisitos, muestra cómo instalarlos
3. Guía para configurar el smart contract:
   - Inicializar proyecto Foundry en `sc/`
   - Instalar dependencias
   - Compilar el contrato
4. Guía para configurar el frontend:
   - Crear proyecto Next.js en `web/`
   - Instalar dependencias (ethers, tailwind, shadcn)
   - Configurar Tailwind CSS
5. Configurar MetaMask:
   - Agregar red Anvil Local
   - Importar cuentas de prueba
6. Mostrar un checklist de configuración completa
