Ayuda a crear un nuevo test para el smart contract SupplyChain.sol.

Instrucciones:
1. Pregunta al usuario qué funcionalidad quiere testear
2. Analiza el contrato en `sc/src/SupplyChain.sol`
3. Revisa los tests existentes en `sc/test/SupplyChain.t.sol`
4. Genera un nuevo test siguiendo las convenciones de Foundry
5. Agrega el test al archivo de tests
6. Ejecuta el test para verificar que funciona
