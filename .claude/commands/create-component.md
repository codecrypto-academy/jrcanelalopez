---
description: Crear un nuevo componente React
---

Ayuda a crear un nuevo componente React para el frontend.

Instrucciones:
1. Pregunta al usuario qué componente necesita crear
2. Analiza la estructura existente en `web/src/components/`
3. Crea el componente siguiendo las convenciones del proyecto:
   - TypeScript
   - 'use client' si usa hooks/localStorage
   - Tailwind CSS para estilos
   - Props tipadas con TypeScript
4. Agrega comentarios explicativos
5. Sugiere dónde usar el componente
