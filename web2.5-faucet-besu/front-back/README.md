# Creating a Next.js Application

Follow these steps to create a Next.js application:

1. **Install Node.js**  
   Ensure you have Node.js installed. You can download it from [Node.js official website](https://nodejs.org/).

2. **Create a New Next.js App**  
   Run the following command in your terminal:

   ```bash
   npx create-next-app@latest my-next-app
   ```

   Replace `my-next-app` with your desired project name.

3. **Navigate to the Project Directory**

   ```bash
   cd my-next-app
   ```

4. **Start the Development Server**

   ```bash
   npm run dev
   ```

   Your application will be available at `http://localhost:3000`.

5. **Edit Your Application**  
   Modify files in the `pages` directory to customize your app.

6. **Build for Production**  
   When ready to deploy, build your app:

   ```bash
   npm run build
   ```

7. **Run the Production Build**  
   Start the production server:
   ```bash
   npm start
   ```

For more details, visit the [Next.js documentation](https://nextjs.org/docs).
